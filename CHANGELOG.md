# Changelog

All notable changes to `dynamic-metal-storefront` are documented in this file.

## [0.1.0] - 2026-11-15
### Added
- Live market-rate ticker for 24K, 22K, 18K gold and silver with manual override controls.
- Dynamic pricing engine calculating metal value (`weight * baseRate * purityMultiplier`), making charges, gemstone value, and 3% GST.
- Interactive product catalog with expandable price-breakdown modal.
- React Context shopping cart, checkout summary, and AI gift-note generator with local fallback.
- Complete Vite + React 18 + TypeScript + Tailwind CSS project configuration and documentation.
